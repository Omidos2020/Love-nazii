# پروژه آغازین Dual Control (Android 10+)

این بسته کد منبع پروژه است، نه APK آماده. برای ساخت APK باید گردش‌کار GitHub Actions اجرا شود.

## ماژول‌ها
- `agent`: برنامه کمکی گوشی اول؛ سرویس محلیِ قابل‌مشاهده با اعلان دائمی و دکمه توقف.
- `controller`: برنامه گوشی دوم؛ IP و کد اتصال را می‌گیرد و وضعیت اتصال را بررسی می‌کند.

## آزمایش
1. هر دو ماژول را نصب کنید.
2. هات‌اسپات گوشی دوم را روشن و گوشی اول را به آن وصل کنید.
3. در گوشی اول Agent را باز و «شروع سرویس اتصال» را بزنید.
4. IP گوشی اول را از جزئیات شبکه Wi-Fi پیدا کنید.
5. در گوشی دوم IP و کد ۶ رقمی نمایش‌داده‌شده در Agent را وارد کنید.

## محدودیت‌ها و امنیت
این نسخه فقط جفت‌سازی ساده و بررسی اتصال محلی را پیاده‌سازی می‌کند؛ انتقال فایل، پیامک، تماس، مخاطبین، اعلان‌ها و نمایش صفحه هنوز پیاده‌سازی نشده‌اند. هیچ داده خصوصی بدون انتخاب و تأیید صاحب گوشی خوانده نمی‌شود.

سرویس پنهان نیست؛ اعلان دائمی دارد و از گوشی اول قابل توقف است. نمونه فعلی از HTTP در شبکه محلی استفاده می‌کند و برای استفاده واقعی باید TLS و احراز هویت قوی‌تری اضافه شود. فقط در شبکه آزمایشی مورد اعتماد استفاده کنید.

## ساخت APK
از تب Actions گردش‌کار `Build Dual Control APKs` را اجرا کنید. پس از موفقیت، artifact با نام `DualControl-Android10-APKs` شامل دو APK آزمایشی خواهد بود.
